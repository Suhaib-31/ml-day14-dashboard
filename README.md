# Day 14 - Data Visualization Dashboard

## Overview

This project demonstrates how to build a simple business analytics dashboard using Python, Pandas, and Matplotlib.

The dashboard provides key performance indicators (KPIs) and visual insights from sales data.

---

## Features

- KPI Metrics
- Sales Trend Analysis
- Profit Trend Analysis
- Orders Visualization
- Profit Distribution Chart
- Dashboard Export

---

## Technologies Used

- Python 3
- Pandas
- Matplotlib

---

## Installation

```bash
pip install pandas matplotlib
```

## Run

```bash
python main.py
```

## Learning Outcomes

- Dashboard Development
- KPI Analysis
- Business Reporting
- Data Visualization
- Data Interpretation
